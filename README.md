# Kalissa Nail Art

Kalissa Nail Art web sitesi. EsteTouch projesinden tamamen bağımsız, ayrı bir projedir.

## Çalıştırma

```
node server.js
```

Site varsayılan olarak http://localhost:5600 adresinde açılır (PORT ortam değişkeniyle değiştirilebilir).

## Yapı

- `server.js` — bağımlılıksız statik dosya sunucusu
- `public/` — site dosyaları (HTML, CSS, JS, görseller)
